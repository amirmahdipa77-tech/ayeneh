# DevKit

جعبه‌ابزار شبکه و برنامه‌نویس — آی‌پی و لوکیشن، جست‌وجوی IP و دامنه، DNS و ابزارهای روزمره. کاملاً استاتیک، بدون سرور، بدون ثبت‌نام.

**سایت:** https://amirmahdipa77-tech.github.io/ayeneh/

## چه دارد

- **آی‌پی شما**: IPv4/IPv6، کشور، شهر، ISP، ASN، مختصات، منطقهٔ زمانی و ارز — با کپی سریع و خروجی JSON.
- **جست‌وجوی IP / دامنه**: هر IPv4، IPv6 یا دامنه؛ اگر دامنه باشد اول با DNS حل می‌شود، بعد موقعیتش می‌آید.
- **DNS**: رکوردهای A / AAAA / MX / TXT / NS / CNAME / SOA / CAA از طریق DNS-over-HTTPS کلادفلر، مستقیم از مرورگر.
- **جعبه‌ابزار**: JSON (مرتب/فشرده/اعتبارسنجی)، Base64 (UTF-8)، URL encode/decode، هش SHA-1/256/384/512، رمزگشای JWT، تبدیل timestamp و UUID v4.
- **دستگاه**: مرورگر، سیستم، صفحه، هسته‌ها، اتصال، پروتکل HTTP، TTFB و GPU.

## چطور کار می‌کند

همه‌چیز در مرورگر اجرا می‌شود؛ هیچ داده‌ای روی سرور ذخیره نمی‌شود. فقط دو سرویس بیرونی صدا زده می‌شوند:

| کار | سرویس | چرا |
| --- | --- | --- |
| آی‌پی و لوکیشن | [ipwho.is](https://ipwho.is) → بعد ipapi.co → بعد ipify | رایگان، بدون کلید، CORS باز |
| DNS | Cloudflare DoH | پاسخ JSON، بدون کلید، CORS باز |

اگر سرویسی جواب نداد، زنجیرهٔ جایگزین امتحان می‌شود و در نهایت آی‌پی خام از ipify نمایش داده می‌شود.

## اجرای محلی

```bash
python3 -m http.server 8000   # بعد http://localhost:8000
```
