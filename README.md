# آینه

تیترهای تازهٔ خبرگزاری‌های ایران و جهان، در یک اپ وب سبک: کارت‌های تصویری، تب‌لیک نیتیو، متن کامل خبر داخل خودِ اپ و ترجمهٔ فوری.

**سایت:** https://amirmahdipa77-tech.github.io/ayeneh/

## چه چیزی می‌سازد

- **فهرست**: کارت‌های عکس‌دار، تب‌های دسته‌بندی (همه / ایران / جهان / ورزش / اقتصاد / فناوری)، جست‌وجو و فیلتر منابع.
- **خواننده**: با کلیک روی هر تیتر، صفحهٔ کامل خبر داخل اپ باز می‌شود (بدون رفتن به سایت منبع) — با عکس، تیتر، متن کامل و نوار پیشرفت مطالعه.
- **ترجمه**: دکمهٔ ترجمه در پایین صفحهٔ خبر، متن را به انگلیسی/عربی/ترکی/آلمانی برمی‌گرداند و با «متن اصلی» به فارسی برمی‌گردد. ترجمه‌ها در مرورگر کش می‌شوند.
- **حس اپلیکیشن**: نوار تب با نشانگر لغزان، موج لمسی (ripple)، لرزش کوتاه، کشیدن به پایین برای تازه‌سازی، کشیدن پایین برای بستن خبر، دکمهٔ بازگشت گوشی (history) و حالت آفلاین با service worker.

## معماری

```
GitHub Actions (هر ۲۰ دقیقه)
   ├─ فید RSS هر خبرگزاری را می‌خواند        scripts/build.mjs
   ├─ متن کامل + og:image خبر را استخراج می‌کند  scripts/lib/article.mjs
   └─ کامیت می‌کند:  data/news.json  +  data/articles/<id>.json

GitHub Pages (استاتیک)
   └─ index.html + assets/*  فقط همین دو فایل JSON را می‌خواند
```

هیچ درخواستی از مرورگر کاربر به سایت‌های خبری نمی‌رود؛ پس نه CORS دردسر دارد، نه در ایران کند می‌شود.

ترجمه سمت مرورگر و با زنجیرهٔ سه سرویس انجام می‌شود (Google translate endpoint، سپس MyMemory). اگر هر دو در دسترس نبودند، پیام روشن نشان داده می‌شود و متن فارسی دست‌نخورده می‌ماند.

## منابع

ایران: ایرنا، ایسنا، مهر، باشگاه خبرنگاران، خبرآنلاین، همشهری، تابناک، عصر ایران، انتخاب، تسنیم، ایلنا، دنیای اقتصاد، ورزش سه، خبر ورزشی، زومیت، دیجیاتو.

جهان (فارسی): بی‌بی‌سی فارسی، ایران اینترنشنال، ایران‌وایر، کیهان لندن، دویچه‌وله فارسی.

## محدودیت‌ها

- چند خبرگزاری (مثل فارس‌نیوز) درخواست خارج از ایران را می‌بندند و عمداً در فهرست نیستند.
- صفحهٔ خبر بعضی سایت‌ها (مثل ایرنا و ایسنا) پشت محافظ Cloudflare است؛ در آن حالت اپ خلاصهٔ خبر را نشان می‌دهد و دکمهٔ «خواندن در منبع» را می‌گذارد.
- اگر یک منبع در یک اجرا خطا بدهد، تیترهای قبلی‌اش تا ۱۲ ساعت نگه داشته می‌شود.

## اجرای محلی

```bash
node scripts/build.mjs          # داده را می‌سازد
python3 -m http.server 8000     # بعد http://localhost:8000
```

## افزودن منبع

در `scripts/build.mjs` به آرایهٔ `SOURCES` اضافه کنید:

```js
{ id: "name", name: "نام فارسی", home: "https://example.ir",
  scope: "ir", cat: "iran", feeds: ["https://example.ir/rss"] },
```

`scope: "world"` یعنی خبر خارجی (تب «جهان»)، `cat` می‌تواند `iran`، `sport`، `tech` یا `economy` باشد.
