# آی‌پی من — DevKit

یک صفحه: پرچم کشور تمام‌عرض، و یک کارت شیشه‌ای که آی‌پی و مشخصات را نشان می‌دهد.

**سایت:** https://amirmahdipa77-tech.github.io/ayeneh/

## چه می‌کند

- آی‌پی را از `ipwho.is` می‌گیرد؛ اگر جواب نداد `ipapi.co` و در نهایت `ipify`.
- کشور را به فارسی از `Intl.DisplayNames` می‌نویسد (بدون جدول ترجمه).
- پرچم کشور را از `flagcdn` در عرض کامل صفحه و با نسبت طبیعی خودش می‌آورد.
- کارت با شفافیت ۱۰٪ و بلور ۲۴px روی پرچم می‌نشیند؛ پرچم از پشت شیشه دیده می‌شود.
- یک لایهٔ اسکریم ملایم داخل شیشه تضمین می‌کند متن روی پرچم‌های روشن هم خوانا بماند.

## انیمیشن‌ها

ورود پرچم، بالا آمدن کارت، ظاهر شدن ردیف‌ها با تأخیر کوتاه و تایپ شدن آی‌پی. همه فقط `transform` و `opacity` هستند و با `prefers-reduced-motion` خاموش می‌شوند.

## ساختار

```
index.html          صفحهٔ تک‌صفحه‌ای
assets/style.css    پرچم، شیشه، انیمیشن
assets/app.js       دریافت آی‌پی + پرچم + تعامل‌ها
sw.js               کش آفلاین پوسته
icons/ , favicon.svg , manifest.webmanifest
```

## اجرای محلی

```bash
python3 -m http.server 8000
```
