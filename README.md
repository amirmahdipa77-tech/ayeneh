# آی‌پی من — DevKit

یک صفحه، یک کارت: کشور، پرچم و آی‌پی شما روی عکس همان کشور.

**سایت:** https://amirmahdipa77-tech.github.io/ayeneh/

## چه می‌کند

- آی‌پی شما (IPv4/IPv6) را از `ipwho.is` می‌گیرد؛ اگر جواب نداد `ipapi.co` و در نهایت `ipify`.
- کشور را به فارسی از `Intl.DisplayNames` می‌نویسد (بدون جدول ترجمه) و پرچم را از `flagcdn` می‌آورد.
- پس‌زمینه: اول پرچم کشور با بلور سنگین به‌عنوان رنگ‌مایه (لحظه‌ای)، بعد عکس واقعی کشور از ویکی‌مدیا کامانز با محو شدن نرم جای آن می‌نشیند.
- کارت شیشه‌ای با شفافیت ۱۰٪ و بلور ۲۶px روی عکس؛ متن سفید با سایهٔ ملایم.
- انیمیشن‌ها: ورود کارت، بالا آمدن ردیف‌ها با تأخیر، تایپ شدن آی‌پی، زوم آرام عکس (Ken Burns) و نور دنبال‌کنندهٔ نشانگر روی شیشه (فقط دسکتاپ).
- همه‌چیز فقط `transform` و `opacity` است و با `prefers-reduced-motion` خاموش می‌شود.

## ساختار

```
index.html          صفحهٔ تک‌صفحه‌ای
assets/style.css    شیشه، لایه‌های پس‌زمینه، انیمیشن
assets/app.js       دریافت آی‌پی + عکس کشور + تعامل‌ها
sw.js               کش آفلاین پوسته
icons/ , favicon.svg , manifest.webmanifest
```

## اجرای محلی

```bash
python3 -m http.server 8000
```
