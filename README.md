# آینه

تیترهای تازهٔ خبرگزاری‌های ایران، در یک صفحهٔ ساده و سریع. بدون سرور، بدون دیتابیس، بدون هزینه.

**سایت:** https://amirmahdipa77-tech.github.io/ayeneh/

## چطور کار می‌کند

- یک کرون‌جاب در GitHub Actions هر ۲۰ دقیقه فید رسمی RSS هر خبرگزاری را می‌خواند.
- اسکریپت `scripts/fetch.mjs` تیتر، لینک، زمان و خلاصهٔ هر خبر را پاک‌سازی می‌کند.
- خروجی در `data/news.json` کامیت می‌شود و سایت همان فایل را می‌خواند.
- صفحه کاملاً استاتیک است: هیچ درخواستی از مرورگر کاربر به سایت‌های خبری نمی‌رود، پس نه مشکل CORS دارد نه کند می‌شود.

## منابع

ایرنا، ایسنا، مهر، باشگاه خبرنگاران جوان، خبرآنلاین، همشهری، تابناک، عصر ایران، انتخاب، تسنیم، ایلنا، دنیای اقتصاد، ورزش سه، خبر ورزشی، زومیت، دیجیاتو.

همهٔ فیدها از صفحهٔ رسمی RSS خودشان برداشته شده‌اند. اگر منبعی در یک اجرا پاسخ ندهد، تیترهای قبلی‌اش (تا ۱۲ ساعت) نگه داشته می‌شود تا صفحه خالی نشود.

## افزودن یا حذف منبع

فایل `scripts/fetch.mjs` را باز کنید و به آرایهٔ `SOURCES` یک عضو اضافه کنید:

```js
{ id: "name", name: "نام فارسی", home: "https://example.ir",
  feeds: ["https://example.ir/rss"] },
```

می‌توانید چند آدرس فید بدهید؛ اسکریپت به ترتیب امتحان می‌کند و اولین آدرسی که جواب بدهد را برمی‌دارد.

## اجرای محلی

```bash
node scripts/fetch.mjs        # داده را می‌سازد
python3 -m http.server 8000   # بعد http://localhost:8000
```

## نکته‌ها

- چند خبرگزاری ایرانی (مثل فارس‌نیوز) درخواست‌های خارج از ایران را می‌بندند؛ آن‌ها عمداً در فهرست نیستند.
- خبرگزاری‌های خارجی فارسی‌زبان (بی‌بی‌سی فارسی، ایران‌اینترنشنال، دویچه‌وله) هم اضافه نشده‌اند تا سایت فقط خبر داخل ایران باشد.
- برای به‌روزرسانی فوری: Actions → update-news → Run workflow.
